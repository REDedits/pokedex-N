App Improvement Suggestions

User request: Suggest improvements to the app.

Findings

1. YouTube search results never reach the UI

getYtubeVids assigns response.data.items to this.ytTitle inside the .then handler and returns ytTitle, but inside that handler this is not the service instance and ytTitle is undeclared. The promise therefore resolves to undefined, so characterCtrl receives no data and immediately dereferences response[0], causing runtime errors and empty video panels.

Task — Ensure YouTube promises resolve with video data

  1. In js/mainService.js, rewrite getYtubeVids so it stores response.data.items in a local constant (no reliance on this) and returns that array from the .then callback.
  2. URL-encode the srcTerm when constructing the request to guard against spaces and special characters.
  3. Verify characterCtrl now receives an array and gracefully handle cases where the array has fewer than three items before updating the scope.

2. Enemy attacks can heal the player

The enemy damage calculation simply subtracts the trainer’s defense from the Pokémon’s attack. Many Pokémon have a base attack below the trainer’s fixed defense of 30, yielding negative damage; subtracting a negative number adds health, so the trainer can get healed when attacked.

Task — Clamp enemy attack damage to non-negative values

  1. In directives/enemyDirective.js, update the attack method to return Math.max(0, this.att - scope.trainer.def) (or another minimum floor) so damage never becomes negative.
  2. Consider incorporating a minimum chip damage to keep battles engaging, and update any UI or logging that reports enemy damage accordingly.
  3. Manually exercise encounters with low-attack Pokémon to confirm the trainer’s health no longer increases after enemy turns.
